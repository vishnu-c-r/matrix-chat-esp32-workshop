// Understanding the Protocol

What is ESP-NOW?

ESP-NOW is a connectionless communication protocol developed by Espressif. Think of it as high-speed walkie-talkies for microcontrollers.

  • 📻 Uses Wi-Fi radio hardware — but does NOT need a Wi-Fi network or router. It operates directly on raw 2.4 GHz action frames.
  • ⚡ Ultra-fast — Messages arrive in under 1 millisecond. No TCP handshakes, no HTTP headers, zero connection delay.
  • 📦 Max 250 bytes per packet — Compact and lightning-fast. Perfectly sized for ~180 chars of chat text plus header metadata.

// Under the Hood

How ESP-NOW Works

  • 1️⃣ Initialize — Set Wi-Fi mode to AP+STA and call esp_now_init()
  • 2️⃣ Register Peer — Set broadcast MAC address (FF:FF:FF:FF:FF:FF) so every node receives
  • 3️⃣ Send — Call esp_now_send() with your packed struct
  • 4️⃣ Receive — An interrupt callback fires automatically the instant a packet arrives
// 1. Initialize ESP-NOW WiFi.mode(WIFI_AP_STA); esp_now_init(); // 2. Register broadcast peer esp_now_peer_info_t peer = {}; memcpy(peer.peer_addr, bcast_mac, 6); esp_now_add_peer(&peer); // 3. Register receive callback esp_now_register_recv_cb(onReceive);

The Packet: Our Message Envelope

Every message is packed into a compact binary Pkt struct — exactly 188 bytes fitting well inside ESP-NOW's 250-byte payload limit.

#pragma pack(push, 1) struct Pkt { uint8_t magic; // Always 0xA5 — "is this our packet?" uint8_t ver; // Protocol version (1) uint8_t type; // CHAT, BEACON, etc. uint8_t node_id; // Who sent this (1-50) uint8_t color_idx; // LED colour index for avatar/LED uint16_t seq; // Incremental sequence counter uint8_t len; // Text length char text[180]; // The actual chat string }; #pragma pack(pop)
// Hardware

NeoPixel LED

A NeoPixel (WS2812) is an individually addressable smart RGB LED. One single data wire controls millions of colours.

  • 🔴🟢🔵 RGB in one package — Red, Green, and Blue LED elements integrated with an onboard IC chip
  • 🔌 Just 3 connections — 5V VCC, Ground, and a single High-Speed Data line on GPIO 2
  • 🎨 16.7 Million colours — 256 brightness levels per channel (256³ = 16,777,216 colours)
  • ⛓️ Chainable — Data-OUT cascaded to next Data-IN. Control hundreds of LEDs from one pin!
// It's literally this easy on ESP32: neopixelWrite( PIN_NEOPIXEL, // GPIO 2 255, // Red (0-255) 0, // Green (0-255) 128 // Blue (0-255) ); // Native built-in ESP32 function! // Zero external libraries required.

Sending a Message

When you click SEND on the captive chat UI, this function executes on your ESP32:

void sendChatMessage(const char* text) { Pkt pkt = {}; pkt.magic = PKT_MAGIC; // 0xA5 — Matrix packet signature pkt.ver = PKT_VER; // Version 1 pkt.type = PktType::CHAT; // Identifies as a user chat pkt.node_id = NODE_ID; // Your assigned ID pkt.color_idx = NODE_ID % N_COLORS; // Your unique colour pkt.seq = g_seq++; // Incremented sequence ID strncpy(pkt.text, text, 179); // Safe bounded string copy pkt.len = strlen(pkt.text); radioSend(&pkt); // Transmit over 2.4 GHz broadcast! }

// Bonus Concept

RSSI → Proximity Detection

Every incoming radio transmission includes an RSSI (Received Signal Strength Indicator). We calculate physical distance from it.

  • 📶RSSI in dBm — Decibels relative to 1 mW. Typically -30 dBm (touching) to -90 dBm (faint edge of range).
  • 📐Log-Distance Path Loss — Formula calculates approximate distance from signal drop-off.
  • 📊EMA Filter — Exponential Moving Average smooths radio multipath reflections and noise.
// Distance estimation formula float estimateDistanceCm(float rssi) { return 100.0f * pow( 10.0f, (-45.0f - rssi) / 30.0f ); } // Smooth noise with EMA filter (α = 0.2) filtered = 0.2 * raw + 0.8 * filtered;
