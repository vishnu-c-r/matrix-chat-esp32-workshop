// Protocol Fundamentals

What is ESP-NOW?

Developed by Espressif, ESP-NOW is a connectionless 2.4 GHz protocol designed for sub-millisecond, low-power microcontroller telemetry.

Feature Standard Wi-Fi (TCP/IP) ESP-NOW (Direct Radio)
Analogy Making a formal phone call Shouting over a Walkie-Talkie
Connection Setup Scan → WPA Handshake → DHCP IP (~3-5 sec) Zero setup — Transmit instantly
Latency 50 ms to 500 ms < 1 millisecond (Instantaneous)
Packet Payload 1,500+ bytes (HTTP + TCP + IP headers) Max 250 bytes (Compact raw data)
📻 REAL-WORLD ANALOGY: Wi-Fi is like posting a registered letter with stamps, envelopes, and receipts. ESP-NOW is picking up a walkie-talkie and pressing Push-to-Talk. Everyone on the channel hears you immediately.
// Under the Hood

How ESP-NOW Works

  • 1️⃣ Initialize Hardware — Set Wi-Fi radio to AP+STA and initialize the ESP-NOW subsystem.
  • 2️⃣ Register Peer — Set broadcast MAC address (FF:FF:FF:FF:FF:FF) so every node in range receives.
  • 3️⃣ Transmit Frame — Call esp_now_send() with your packed binary struct.
  • 4️⃣ Receive Callback — Hardware interrupt triggers the callback function automatically when a packet arrives.
// 1. Initialize Wi-Fi and ESP-NOW WiFi.mode(WIFI_AP_STA); esp_now_init(); // 2. Add broadcast peer (FF:FF:FF:FF:FF:FF) esp_now_peer_info_t peer = {}; memcpy(peer.peer_addr, bcast_mac, 6); esp_now_add_peer(&peer); // 3. Register asynchronous callback esp_now_register_recv_cb(onReceive);

File Type What It Contains Real-World Analogy

// Object-Oriented Embedded C++

OOP & C++ in Microcontrollers

Modern embedded systems rely on C++ design patterns to write safe, maintainable, and lightning-fast code.

  • 📦 Encapsulation — Hardware modules are self-contained. led.cpp manages PWM; radio.cpp manages wireless frames.
  • 🏷️ Type-Safe Scoped Enums — enum class PktType : uint8_t prevents dangerous casting bugs compared to old C #defines.
  • ⚡ Event Callbacks — Passing function pointers (onPktRecv) enables asynchronous, non-blocking hardware interrupts.
  • 📐 Memory Alignment Control — #pragma pack(push, 1) forces raw binary layouts without CPU padding!
// 1. Scoped enum with explicit uint8_t size enum class PktType : uint8_t { CHAT = 0, SYS_SYNC = 1, SYS_ALERT = 2 }; // 2. Packed binary struct (1-byte alignment) #pragma pack(push, 1) struct Pkt { uint8_t magic; // Signature 0xA5 PktType type; // Type-safe enum uint8_t node_id; }; #pragma pack(pop)
// Data Serialization

The Packet: Our Message Envelope

Every message is packed into an exact 188-byte binary Pkt struct. Exactly the same byte sequence in RAM on every ESP32.

magic0xA51 byte
ver11 byte
typeCHAT1 byte
node_id141 byte
color_idx41 byte
seq13372 bytes
len111 byte
text"Hello World"180 bytes
⚠️ WHY #pragma pack MATTERS: 32-bit CPUs love aligning variables to 4-byte boundaries. Without #pragma pack(1), the compiler inserts hidden blank "padding bytes", corrupting the message when received by another board!
// Hardware Deep Dive

NeoPixel LED: WS2812

A NeoPixel is an individually addressable smart RGB LED. One single GPIO controls millions of colors!

  • 🔌 The Problem — Standard RGB LEDs need 3 PWM pins each. Wiring 10 LEDs requires 30 microcontroller pins!
  • 💡 The Solution — The WS2812 contains a microscopic microcontroller integrated inside the LED lens.
  • ⚡ 800 kHz Pulse Protocol — Data is encoded by high/low microsecond pulse widths over a single wire on GPIO 2.
  • 🎨 24-bit TrueColor — 8 bits Green + 8 bits Red + 8 bits Blue = 16.7 Million Colors!
// One native built-in function call! // No bloated third-party libraries needed: neopixelWrite( PIN_NEOPIXEL, // GPIO 2 on C3 255, // Red (0-255) 0, // Green (0-255) 128 // Blue (0-255) ); // Formula for total colors: // 256 × 256 × 256 = 16,777,216
// Real-Time Systems

Why delay() Kills Embedded Code

Calling delay(1000) puts the entire CPU to sleep. During that second, incoming radio packets and web requests are dropped!

Approach How It Works Real-World Analogy
Blocking (delay) Halts CPU execution loop entirely Frozen Chef: Standing with eyes closed for 20 mins while rice boils, ignoring phone calls and fires!
Non-Blocking (millis) Checks elapsed time on every loop cycle Smart Chef: Glances at wristwatch periodically, keeps stirring food, answers door.
// Smooth breathing animation computed from current timestamp — ZERO delay()! float phase = (millis() % 3000) * (2.0f * 3.14159f / 3000.0f); float brightness = 0.05f + 0.20f * (0.5f + 0.5f * sinf(phase)); setRgb(color.r * brightness, color.g * brightness, color.b * brightness);

Sending a Message

When you click SEND on the captive chat UI, this function executes on your ESP32:

void sendChatMessage(const char* text) { Pkt pkt = {}; pkt.magic = PKT_MAGIC; // 0xA5 — Matrix packet signature pkt.ver = PKT_VER; // Version 1 pkt.type = PktType::CHAT; // Identifies as a user chat pkt.node_id = NODE_ID; // Your assigned ID (from config.h) pkt.color_idx = NODE_ID % N_COLORS; // Your unique colour pkt.seq = g_seq++; // Incremented sequence ID strncpy(pkt.text, text, 179); // Safe bounded string copy pkt.len = strlen(pkt.text); radioSend(&pkt); // Transmit over 2.4 GHz broadcast! }

// Radio Physics

RSSI → Distance Physics

Every incoming radio transmission includes an RSSI (Received Signal Strength Indicator). We calculate physical distance from it.

  • 📶RSSI in dBm — Measured in decibels relative to 1 mW. -30 dBm (touching) to -90 dBm (faint edge of range).
  • 📐Log-Distance Path Loss — Formula calculates approximate distance in centimeters from radio dropoff.
  • 📊EMA Smoothing — Exponential Moving Average filters out multipath wave reflections.
// Free Space Path Loss distance formula float estimateDistanceCm(float rssi) { return 100.0f * pow( 10.0f, (-45.0f - rssi) / 30.0f ); } // EMA Filter (α = 0.2): filtered = 0.2 * raw + 0.8 * filtered;

Unit Testing for Firmware

Why do professional firmware developers write unit tests on their laptops before touching physical hardware?

  • ⚡Speed — Flashing silicon takes 1–2 minutes. Running tests natively on your PC takes 2 seconds!
  • 🧪Memory Bounds — Catch buffer overflows, pointer crashes, and struct sizing bugs before soldering.
  • 🛠️Unity Test Framework — Industry-standard embedded testing engine in PlatformIO (test/ folder).
// Example Unit Test running on Desktop Host: void test_packet_fits_in_espnow() { // ESP-NOW limit is strictly 250 bytes TEST_ASSERT_LESS_OR_EQUAL(250, sizeof(Pkt)); } void test_deduplication() { TEST_ASSERT_FALSE(dedupeSeen(1, 100)); TEST_ASSERT_TRUE(dedupeSeen(1, 100)); // Duplicate! }
